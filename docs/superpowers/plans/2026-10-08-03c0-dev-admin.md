# Dev-админ «admin» — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** аккаунт dev-логина `admin` (`discordId = "dev:admin"`) ничего не тратит и не замораживается — чтобы удобно тестировать игру локально.

**Architecture:** движок держит в памяти множество «безлимитных» `userId` (не персистится). Его наполняют два места: dev-логин с именем `admin` и старт сервера при `DEV_LOGIN=1` (сессии переживают рестарт, повторного логина нет). `PlayerView` получает флаг `unlimited`, клиент показывает ∞ и не блокирует предпроверкой.

**Tech Stack:** bun test, TypeScript, существующие GameEngine / Hub / tRPC / React.

---

## Решения (согласованы)

- Идентификация: только `discordId === "dev:admin"`. Настоящий Discord ID — число, поэтому в проде такой аккаунт невозможен; dev-логин существует только при `DEV_LOGIN=1` на localhost. Ник Discord «admin» прав **не** даёт.
- Безлимит: заряды пикселей, бомбы в инвентаре, лимит активных бомб, детектор и дефьюзер. Монеты и магазин — как у всех.
- Взрыв: срабатывает (бомба снимается, вспышка, автор бомбы получает бонус и статистику), но жертва-админ не замораживается и не теряет монеты. Старая заморозка тоже игнорируется.
- Статистика и рейтинги: как у обычного игрока.
- Rate limit WebSocket (20/с, burst 40) не меняется.
- Это не «админка» из спеки (`ADMIN_DISCORD_IDS`, План 5) — только dev-чит.

```
 /auth/dev?name=admin ──► upsertUser(dev:admin) ──► engine.grantUnlimited(id)
 main.ts (DEV_LOGIN=1) ──► SELECT id WHERE discord_id='dev:admin' ──► engine.grantUnlimited(id)

 engine.placePixel/detect/defuse/explode ── isUnlimited? ──► не тратить / не морозить
 toPlayerView(..., unlimited) ──► PlayerView.unlimited ──► HUD «∞», предпроверка пропускает
```

```ts
import { eq } from "drizzle-orm";
import type { Db } from "../db/client";
import { users } from "../db/schema";
import type { GameEngine } from "../engine/engine";

/** Only dev login can create this id: real Discord ids are numeric. */
export const DEV_ADMIN_DISCORD_ID = "dev:admin";

/** Sessions outlive restarts, so the grant is restored at boot. Call only when dev login is enabled. */
export async function restoreDevAdmin(db: Db, engine: GameEngine): Promise<void> {
  const [row] = await db.select({ id: users.id }).from(users).where(eq(users.discordId, DEV_ADMIN_DISCORD_ID)).limit(1);
  if (row) engine.grantUnlimited(row.id);
}
```
