# План 10: игра на новом ките — Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** игровой клиент по спеке ревизии (раздел 3) на компонентах `ui/kit` из плана 9: раскладки десктоп / телефон, верхняя полоса, док с инструментами и палитрой, разделы, чат, состояния. Все строки — через i18n. Старые компоненты (`Hud`, `StatusBar`, `PanelMenu`, `AuthPanel`, `SidePanel`, `Feed`, `PaletteBar`, `ConfirmBar`, `AccessBanner`, `FreezeBanner`, `Toasts`, `Tabs.module.css`) удаляются. Игровые правила и протокол не меняются (кроме одного необязательного поля, см. ниже).

**Решения:**

- **Раскладка** — `GameLayout` выбирает `desktop` / `mobile` по `matchMedia("(min-width: 900px)")` (хук `useIsDesktop`), не по user agent. Холст и сессия одни на обе раскладки и не пересоздаются при смене.
- **Сдвиг холста под панель** (десктоп): у контейнера холста правый отступ = ширина панели + столбец. `ResizeObserver` сессии уже пересчитывает камеру при изменении размера, центр остаётся в той же точке мира, поэтому видимая картинка сдвигается на половину ширины панели. Математика камеры не меняется.
- **Призрак под курсором** (десктоп) — новый `setGhost(cell, colorId)` в рендерере (рамка и заливка клетки в оверлее), координаты — DOM-подпись рядом с курсором.
- **Онлайн** — к сообщению `online` добавляется необязательное поле `sample: UserRef[]` (до трёх недавно подключившихся игроков) для мини-аватаров. Поле необязательное, старые клиенты его игнорируют, `PROTOCOL_VERSION` не меняется.
- **Аватары** — инициал на цвете от id (`Avatar` из кита). `UserRef` не несёт картинку Discord; добавить её — отдельная задача.
- **Лента** — `timeline-store` вместо `feed-store`: события и сообщения вместе, лимит `config.chat.historySize`, удаление по `chat_deleted`, счётчик непрочитанных (только сообщения других игроков, сбрасывается, когда лента видна и прокручена вниз).
- **Тосты** — тон (`error` / `success` / `info`) и иконка; повтор того же текста увеличивает счётчик «×N» вместо новой строки. Тексты тостов — ключи i18n с параметрами, без эмодзи.
- **Недавние цвета** (телефон) — 8 последних выбранных, в `localStorage`.
- **Модерация в игре** — до админского «Холста» (план 11) остаётся вкладкой панели у админа (кнопка в столбце с пунктирной рамкой). Инспектор и выделение области переезжают из дока в шапку этой вкладки. План 11 заменит вкладку ссылкой на `/admin/canvas`.
- **Визуальная регрессия** (спека 8) — отдельным шагом после плана 11, когда готовы и игра, и админка: эталоны снимаются один раз.

## Задачи

### 1. Состояние и логика
- [x] `timeline-store`: `replace`, `push`, `remove(ids)`, лимит, непрочитанные (`markRead`), фильтр событий (`showEvents`, в `localStorage`).
- [x] `ui-store`: тосты с тоном, иконкой и счётчиком; недавние цвета; раздел `chat` (шторка), высота шторки, открытая сетка палитры, свёрнутый чат; `profileUserId` как было.
- [x] `chatApi.send` (`{ ok, code, retryAt?, until? }`) и `adminChatApi.delete`.
- [x] Хоткеи (`1–3`, `B`, `Q/E`, `Esc`) — чистая функция «клавиша → действие» и один обработчик на окне; не срабатывают в полях ввода.
- [x] Тексты `game/*` (дефьюзер, награды, взрыв, предметы магазина, доски рейтинга) — в словари ru/en.
- [x] Сервер: `online.sample`; клиент: `game-store.onlineSample`.
- [x] Тесты: лента (лимит, удаление, непрочитанные, история), тосты (счётчик), недавние цвета, хоткеи, онлайн-выборка в хабе.

### 2. Каркас
- [x] `useIsDesktop`, `GameLayout` (десктоп / телефон), контейнер холста с отступом под панель.
- [x] Верхняя полоса: логотип, онлайн (мини-аватары + число, статус соединения с `data-testid="status"`), заряды (`ChargeMeter`: сегменты, `7/10`, таймер; при `max > 15` — число и полоса), монеты (подсветка изменения и `+15` / `−30`), меню игрока (профиль, язык, админка, выход) или «Войти через Discord» (и dev-вход в dev-сборке).
- [x] Столбец разделов (десктоп): магазин, награда (бейдж), рейтинги, профиль; миникарта; модерация у админа. Панель 392 px с заголовком и закрытием; `Esc` и повторный клик закрывают.
- [x] Док (десктоп): инструменты (радиогруппа с подписями и счётчиками; инструмент с нулём открывает магазин), «+ бомба» (`×N`, при нуле — подсказка и магазин), палитра всеми цветами 20 в ряд (закрытые с замком ведут в магазин, эффекты анимированы).
- [x] Рендерер: `setGhost`; подпись координат у курсора.
- [x] Телефон: верхняя строка, полоска чата (последнее сообщение, счётчик), док в две строки (инструменты · «+ бомба» · разделы; недавние цвета · «Все» с сеткой 8×N), режим подтверждения (Отмена + большая кнопка действия в выбранном цвете + координаты), шторка с вкладками Чат · Магазин · Награда · Рейтинг · Профиль (+ Модерация у админа).
- [x] Миникарта: справа внизу на десктопе (скрыта при открытой панели), переключатель в столбце.

### 3. Разделы
- [x] Магазин: баланс; «Снаряжение» карточками (иконка в плашке, название, назначение, «у вас N», кнопка с ценой или «не хватает N»; подтверждение дорогих покупок); «Цвета» сеткой 4 в ряд с названием, живым превью и ценой или «есть». Переход к товару из дока подсвечивает карточку.
- [x] Награда дня: 7 дней списком (десктоп) или большая карточка «сегодня» и полоса из 7 ячеек (телефон); подпись про пропуск и время следующей награды по часовому поясу конфига.
- [x] Рейтинги: 5 досок иконками с подписями (на телефоне — скролл чипов), период `Segmented`, подиум топ-3, список, своя строка закреплена внизу.
- [x] Профиль: аватар, имя, дата; инвентарь строкой (свой); две главные цифры; остальное списком; тепловая карта с легендой; в своём — язык RU / EN (`settings.setLocale`) и «Выйти»; у админа в чужом — «Модерировать».
- [x] Модерация (админ): вкладка с переключателем «Клетка / Область» в шапке, остальное — как в v1, стили кита.

### 4. Чат
- [x] `ChatFeed`: сообщения (аватар, имя, время, текст; свои — имя розовым), события компактными строками с иконкой; `aria-live="polite"`; автопрокрутка, пока лента внизу, иначе кнопка «N новых ↓».
- [x] `ChatComposer`: `Enter` и кнопка; ошибки под полем (лимит частоты со временем, длина, отключение), текст не теряется; гость — «Войдите, чтобы писать»; бан или отключение — причина и срок.
- [x] Десктоп: блок 288 px слева внизу, сворачивается до заголовка, переключатель событий, счётчик непрочитанных на свёрнутом. Телефон: вкладка шторки, поле над клавиатурой, переключатель событий слева от поля.
- [x] Админ: «Удалить» у сообщения.
- [x] Тесты: прокрутка и «N новых», непрочитанные, ошибки отправки, гость и отключённый.

### 5. Состояния
- [x] Заморозка: ледяная плашка с иконкой, «Вы подорвались на бомбе X», штраф, крупный таймер; инструменты и подтверждение заблокированы.
- [x] Нет доступа (бан, возраст, гильдия): тонкая плашка под верхней полосой с причиной и сроком; док «только смотреть». Гость — кнопка «Войти через Discord» вместо инструментов.
- [x] Соединение: «Переподключение…» в верхней полосе, док неактивен; устаревшая версия — «Игра обновилась» и кнопка «Обновить».
- [x] Тосты: одна строка в рамке цвета исхода с иконкой, «×N», постоянно смонтированные регионы `role="alert"` / `role="status"`.
- [x] Взрыв: вспышка в клетке, короткая вспышка экрана, вибрация (как в v1).

### 6. Чистка и проверки
- [x] Удалить старые компоненты и их стили; `feed-store` → `timeline-store`.
- [x] e2e: локаль `ru-RU` в Playwright; сценарий v1 (пиксель виден второму игроку) на новых подписях; раскладка в 1440×900 и 390×844 — верхняя полоса, док и чат не перекрываются, на десктопе видна вся палитра, на телефоне тап → подтверждение → пиксель.
- [x] lint, typecheck, тесты, сборка, e2e; скриншоты обеих раскладок для отчёта; push; CI зелёный.
