# План 3b: Игровое управление — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Клиент, в который можно играть: войти, выбрать цвет, поставить пиксель (мышь — сразу, касание — выбор клетки и кнопка «Поставить»), включить режим бомбы, видеть заряды с таймером восстановления, монеты, заморозку, получать понятные ошибки, пережить взрыв с эффектом.

**Architecture:** Вся логика — в чистых модулях с тестами: расчёт зарядов, предпроверка размещения, ожидающие размещения, тексты ошибок, ui-стор, `GameClient`. `GameClient` общается с холстом через узкий интерфейс `CanvasPort` (его реализует `CanvasSession`), поэтому тестируется с фейковым портом. Ожидающие пиксели рисуются **оверлеем поверх чанков**, а не правкой данных чанка: откатывать нечего — при отказе оверлей просто пропадает, а настоящий пиксель приходит дельтой (она публикуется раньше ответа `placed`). Pixi-оверлей, эффект взрыва и React-компоненты проверяются вручную в браузере.

**Tech Stack:** как в Плане 3a (Vite 8.3.3, React 19.3, PixiJS 8.22, zustand 5.0.15, CSS Modules, `bun test`).

**Спека:** `docs/superpowers/specs/2026-10-07-rave-battle-design.md` (2.2, 2.3, 3.7). **Роадмап:** `docs/superpowers/plans/2026-10-07-00-roadmap.md` («Заметки для Плана 3b» — учтены: jitter переподключения, сохранение query-параметров, обработка `login_error`).

**Решения этого плана:**
- Разбивка: **3b** — этот план; **3c** — детектор/дефьюзер (tRPC-клиент + TanStack Query, оверлей цифр, localStorage), миникарта. tRPC-клиент в 3b не нужен: пиксели идут по WebSocket.
- Ввод: `pointerType === "touch"` → тап выбирает клетку (рамка), кнопка «Поставить» подтверждает; мышь и перо → клик ставит сразу. Анонимам любой тап показывает «Войдите, чтобы рисовать».
- Клиентская предпроверка (чтобы не слать заведомо отказы): вход, наличие игрока, бан, заморозка, цвет открыт, заряды минус ожидающие, бомбы минус ожидающие. Сервер остаётся арбитром; его коды отказов показываются теми же текстами.
- Ожидающие размещения: оверлей (полупрозрачный цвет + розовая рамка), таймаут ожидания 10 с (тост «Нет ответа»), при потере соединения очищаются. Ответ `placed` с неизвестным `reqId` игнорируется.
- Заряды на клиенте считаются по тем же правилам, что в движке: `max(chargesUpdatedAt, frozenUntil)` — точка отсчёта, шаг `regenMs`, потолок `chargeCap`. Часы клиента могут расходиться с серверными. **Исправлено по финальному ревью:** это влияет не только на таймер — при отстающих часах клиентская предпроверка считает заряды/заморозку неверно и блокирует отправку (игрок с часами, отстающими на час, не может ставить пиксели). Поправка на расхождение (`serverNow` в `hello`/`player`) — обязательный пункт Плана 3c.
- Взрыв: тост с текстом, кольцо-вспышка на клетке (Pixi, 700 мс), CSS-вспышка экрана (при `prefers-reduced-motion` без движения), баннер заморозки с обратным отсчётом.
- Выбор цвета и (не)включённый режим бомбы: цвет хранится в `localStorage` (`rb:color`, с `try/catch`; недоступное хранилище → значение по умолчанию 5), режим бомбы — нет. Заблокированные цвета (`unlock ≠ "default"` и не открыты игроком) показаны с замком; клик → информационный тост.
- Вход: кнопка «Войти через Discord» (`/auth/discord`); в dev-сборке (`import.meta.env.DEV`) — ещё поле имени dev-входа (`/auth/dev?name=`). Выход — `POST /auth/logout` (браузер сам добавляет `Origin`), соединение закроется кодом 4001 и переподключится анонимно.
- `?login_error=denied|discord|state` при загрузке → тост и удаление параметра из URL; запись позиции камеры в URL сохраняет прочие параметры и hash.
- Переподключение с jitter (`delay × (0.5…1.0)`); для тестов `random` внедряется.
- Тестов для React-компонентов нет (в проекте нет DOM-окружения для `bun test`); они проверяются вручную в Task 10.

```ts
import type { PlayerView } from "@rave/shared";

type ChargeState = Pick<PlayerView, "charges" | "chargesUpdatedAt" | "chargeCap" | "frozenUntil">;

/**
 * Charges at `now`, using the engine's rule: regeneration is paused while frozen and counts from
 * max(chargesUpdatedAt, frozenUntil). `nextAt` is when the next charge arrives (null when full).
 */
export function chargesAt(p: ChargeState, regenMs: number, now: number): { charges: number; nextAt: number | null } {
  if (p.charges >= p.chargeCap) return { charges: p.chargeCap, nextAt: null };
  const from = Math.max(p.chargesUpdatedAt, p.frozenUntil);
  const gained = now > from ? Math.floor((now - from) / regenMs) : 0;
  const charges = Math.min(p.chargeCap, p.charges + gained);
  if (charges >= p.chargeCap) return { charges, nextAt: null };
  return { charges, nextAt: from + (gained + 1) * regenMs };
}

export function isFrozen(p: Pick<PlayerView, "frozenUntil">, now: number): boolean {
  return p.frozenUntil > now;
}
```

```ts
import type { GameConfig, PlayerView, UserRef } from "@rave/shared";
import { chargesAt, isFrozen } from "./charges";

export interface PlacementInput {
  user: UserRef | null;
  player: PlayerView | null;
  config: GameConfig;
  colorId: number;
  withBomb: boolean;
  /** Placements sent but not yet answered; they will consume charges and bombs. */
  pendingCount: number;
  pendingBombs: number;
  now: number;
}

export type PlacementPlan = { ok: true } | { ok: false; code: string };

/** Client-side pre-check so obviously doomed requests are not sent. The server stays the authority. */
export function planPlacement(i: PlacementInput): PlacementPlan {
  if (!i.user) return { ok: false, code: "unauthorized" };
  const p = i.player;
  if (!p) return { ok: false, code: "unavailable" };
  if (p.bannedUntil === "permanent" || (p.bannedUntil !== null && p.bannedUntil > i.now)) return { ok: false, code: "banned" };
  if (isFrozen(p, i.now)) return { ok: false, code: "frozen" };
  const entry = i.config.palette.find((e) => e.id === i.colorId);
  if (!entry) return { ok: false, code: "invalid_color" };
  if (entry.unlock !== "default" && !p.unlockedColors.includes(i.colorId)) return { ok: false, code: "color_locked" };
  if (chargesAt(p, i.config.charges.regenMs, i.now).charges - i.pendingCount < 1) return { ok: false, code: "no_charges" };
  if (i.withBomb && p.inventory.bomb - i.pendingBombs < 1) return { ok: false, code: "no_bombs" };
  return { ok: true };
}
```

```ts
export interface Pending {
  reqId: number;
  x: number;
  y: number;
  colorId: number;
  withBomb: boolean;
  at: number;
}

/** Placements sent to the server and not answered yet. */
export class PendingPlacements {
  private items = new Map<number, Pending>();
  private nextId = 1;

  add(cell: { x: number; y: number }, colorId: number, withBomb: boolean, now: number): Pending {
    // The wire format has a u32 request id.
    const reqId = this.nextId;
    this.nextId = this.nextId >= 0xffff_ffff ? 1 : this.nextId + 1;
    const pending = { reqId, x: cell.x, y: cell.y, colorId, withBomb, at: now };
    this.items.set(reqId, pending);
    return pending;
  }

  resolve(reqId: number): Pending | undefined {
    const pending = this.items.get(reqId);
    this.items.delete(reqId);
    return pending;
  }

  /** Removes and returns entries sent more than `ttlMs` ago. */
  expire(now: number, ttlMs: number): Pending[] {
    const gone = [...this.items.values()].filter((p) => now - p.at >= ttlMs);
    for (const p of gone) this.items.delete(p.reqId);
    return gone;
  }

  clear(): void {
    this.items.clear();
  }

  list(): Pending[] {
    return [...this.items.values()];
  }

  get size(): number {
    return this.items.size;
  }

  get bombs(): number {
    return this.list().filter((p) => p.withBomb).length;
  }
}
```

```ts
import { useStore } from "zustand";
import { createStore } from "zustand/vanilla";

export type StorageLike = Pick<Storage, "getItem" | "setItem">;

export interface Toast {
  id: number;
  kind: "error" | "info";
  text: string;
}

export interface ExplosionInfo {
  id: number;
  self: boolean;
  coinsLost: number;
  frozenUntil: number;
  bombOwner: string;
  at: number;
}

export interface UiState {
  selectedColor: number;
  bombMode: boolean;
  /** Cell picked by a touch tap, waiting for confirmation. */
  selection: { x: number; y: number } | null;
  toasts: Toast[];
  explosion: ExplosionInfo | null;
  selectColor(id: number): void;
  setBombMode(on: boolean): void;
  select(cell: { x: number; y: number } | null): void;
  pushToast(kind: Toast["kind"], text: string): number;
  dismissToast(id: number): void;
  setExplosion(info: Omit<ExplosionInfo, "id"> | null): void;
}

const COLOR_KEY = "rb:color";
const MAX_TOASTS = 4;
/** Yellow in the default palette: visible on the black board. */
export const DEFAULT_COLOR = 5;

function readColor(storage: StorageLike | null): number {
  try {
    const raw = storage?.getItem(COLOR_KEY);
    const value = raw == null ? Number.NaN : Number(raw);
    return Number.isInteger(value) && value >= 0 && value <= 255 ? value : DEFAULT_COLOR;
  } catch {
    return DEFAULT_COLOR;
  }
}

export function createUiStore(storage: StorageLike | null) {
  let nextId = 1;
  return createStore<UiState>()((set) => ({
    selectedColor: readColor(storage),
    bombMode: false,
    selection: null,
    toasts: [],
    explosion: null,
    selectColor: (id) => {
      try {
        storage?.setItem(COLOR_KEY, String(id));
      } catch {
        // Private mode or blocked storage: the choice just won't survive a reload.
      }
      set({ selectedColor: id });
    },
    setBombMode: (bombMode) => set({ bombMode }),
    select: (selection) => set({ selection }),
    pushToast: (kind, text) => {
      const id = nextId++;
      set((s) => ({ toasts: [...s.toasts, { id, kind, text }].slice(-MAX_TOASTS) }));
      return id;
    },
    dismissToast: (id) => set((s) => ({ toasts: s.toasts.filter((t) => t.id !== id) })),
    setExplosion: (info) => set({ explosion: info ? { ...info, id: nextId++ } : null }),
  }));
}

function browserStorage(): StorageLike | null {
  try {
    return typeof window === "undefined" ? null : window.localStorage;
  } catch {
    return null;
  }
}

export const uiStore = createUiStore(browserStorage());

export function useUi<T>(selector: (state: UiState) => T): T {
  return useStore(uiStore, selector);
}
```

```ts
import type { ServerMessage } from "@rave/shared";
import type { StoreApi } from "zustand/vanilla";
import type { Timers } from "../net/socket";
import type { GameState } from "../state/game-store";
import type { UiState } from "../state/ui-store";
import { rejectText } from "./messages";
import { PendingPlacements } from "./pending";
import { planPlacement } from "./placement";

type Cell = { x: number; y: number };
type PlacedMessage = Extract<ServerMessage, { type: "placed" }>;

/** What the game logic needs from the canvas; implemented by `CanvasSession`. */
export interface CanvasPort {
  /** False when the frame cannot be sent right now (not connected). */
  sendPlace(message: { reqId: number; x: number; y: number; colorId: number; withBomb: boolean }): boolean;
  setPending(cells: Array<{ x: number; y: number; colorId: number }>): void;
  setSelection(cell: Cell | null): void;
  flash(cell: Cell): void;
}

export interface ClientDeps {
  game: StoreApi<GameState>;
  ui: StoreApi<UiState>;
  now?: () => number;
  timers?: Timers;
  pendingTtlMs?: number;
}

const defaultTimers: Timers = {
  set: (fn, ms) => setTimeout(fn, ms),
  clear: (handle) => clearTimeout(handle as ReturnType<typeof setTimeout>),
};

/** Turns taps into placements and server answers into UI feedback. */
export class GameClient {
  private port: CanvasPort | null = null;
  private readonly pending = new PendingPlacements();
  private unsubscribe: Array<() => void> = [];
  private readonly now: () => number;
  private readonly timers: Timers;
  private readonly ttlMs: number;

  constructor(private readonly deps: ClientDeps) {
    this.now = deps.now ?? Date.now;
    this.timers = deps.timers ?? defaultTimers;
    this.ttlMs = deps.pendingTtlMs ?? 10_000;
  }

  attach(port: CanvasPort): void {
    this.detach();
    this.port = port;
    this.unsubscribe = [
      this.deps.game.subscribe((state, prev) => {
        // Answers sent before a disconnect will never arrive.
        if (prev.status === "open" && state.status !== "open") this.dropPending();
      }),
      this.deps.ui.subscribe((state, prev) => {
        if (state.selection !== prev.selection) this.port?.setSelection(state.selection);
      }),
    ];
  }

  detach(): void {
    for (const off of this.unsubscribe) off();
    this.unsubscribe = [];
    this.pending.clear();
    this.port = null;
  }

  readonly onCellTap = (cell: Cell, pointerType: string): void => {
    if (!this.deps.game.getState().user) {
      this.toast("unauthorized");
      return;
    }
    if (pointerType === "touch") {
      this.deps.ui.getState().select(cell);
      return;
    }
    this.place(cell);
  };

  readonly confirmSelection = (): void => {
    const selection = this.deps.ui.getState().selection;
    if (!selection) return;
    this.deps.ui.getState().select(null);
    this.place(selection);
  };

  readonly cancelSelection = (): void => {
    this.deps.ui.getState().select(null);
  };

  readonly onPlaced = (message: PlacedMessage): void => {
    const placed = this.pending.resolve(message.reqId);
    if (!placed) return;
    this.port?.setPending(this.pending.list());
    const result = message.result;
    if (!result.ok) {
      this.toast(result.code);
      return;
    }
    if (result.outcome === "placed") return;
    this.port?.flash({ x: placed.x, y: placed.y });
    this.deps.ui.getState().setExplosion({
      self: result.self,
      coinsLost: result.coinsLost,
      frozenUntil: result.frozenUntil,
      bombOwner: result.bombOwner.name,
      at: this.now(),
    });
    const text = result.self
      ? `Вы подорвались на собственной бомбе! −${result.coinsLost} монет, заморозка`
      : `💥 Бомба игрока ${result.bombOwner.name}! −${result.coinsLost} монет, заморозка`;
    this.deps.ui.getState().pushToast("error", text);
  };

  private place(cell: Cell): void {
    const game = this.deps.game.getState();
    const ui = this.deps.ui.getState();
    if (!game.config) return;
    const now = this.now();
    const plan = planPlacement({
      user: game.user,
      player: game.player,
      config: game.config,
      colorId: ui.selectedColor,
      withBomb: ui.bombMode,
      pendingCount: this.pending.size,
      pendingBombs: this.pending.bombs,
      now,
    });
    if (!plan.ok) {
      this.toast(plan.code);
      return;
    }
    const placement = this.pending.add(cell, ui.selectedColor, ui.bombMode, now);
    const sent = this.port?.sendPlace({
      reqId: placement.reqId,
      x: placement.x,
      y: placement.y,
      colorId: placement.colorId,
      withBomb: placement.withBomb,
    });
    if (!sent) {
      this.pending.resolve(placement.reqId);
      this.toast("unavailable");
      return;
    }
    this.port?.setPending(this.pending.list());
    this.timers.set(() => this.expire(), this.ttlMs + 50);
  }

  private expire(): void {
    if (this.pending.expire(this.now(), this.ttlMs).length === 0) return;
    this.port?.setPending(this.pending.list());
    this.toast("timeout");
  }

  private dropPending(): void {
    if (this.pending.size === 0) return;
    this.pending.clear();
    this.port?.setPending([]);
  }

  private toast(code: string): void {
    this.deps.ui.getState().pushToast("error", rejectText(code));
  }
}
```

```ts
  private screenX(wx: number): number {
    return (wx - this.camera.x) * this.camera.zoom + this.app.screen.width / 2;
  }

  private screenY(wy: number): number {
    return (wy - this.camera.y) * this.camera.zoom + this.app.screen.height / 2;
  }

  private rgbOf(colorId: number): number {
    const i = colorId * 4;
    return ((this.lut[i] ?? 0) << 16) | ((this.lut[i + 1] ?? 0) << 8) | (this.lut[i + 2] ?? 0);
  }

  /** Pending pixels and the selection frame, drawn in screen space like the grid. */
  private drawOverlay(): void {
    this.overlay.clear();
    const zoom = this.camera.zoom;
    for (const p of this.pendingCells) {
      this.overlay
        .rect(this.screenX(p.x), this.screenY(p.y), zoom, zoom)
        .fill({ color: this.rgbOf(p.colorId), alpha: 0.6 })
        .stroke({ width: 2, color: 0xff2bd6, alpha: 0.9 });
    }
    const sel = this.selectedCell;
    if (sel) {
      this.overlay.rect(this.screenX(sel.x) + 1, this.screenY(sel.y) + 1, Math.max(zoom - 2, 4), Math.max(zoom - 2, 4)).stroke({ width: 2, color: 0x22f3ff, alpha: 1 });
    }
  }

  private tickFlashes(): void {
    if (this.flashes.length === 0) {
      if (this.fxDrawn) {
        this.fx.clear();
        this.fxDrawn = false;
      }
      return;
    }
    const now = performance.now();
    this.flashes = this.flashes.filter((f) => now - f.start < FLASH_MS);
    this.fx.clear();
    this.fxDrawn = true;
    const zoom = Math.max(this.camera.zoom, 6);
    for (const f of this.flashes) {
      const t = (now - f.start) / FLASH_MS;
      this.fx
        .circle(this.screenX(f.x + 0.5), this.screenY(f.y + 0.5), zoom * (0.6 + t * 3.5))
        .stroke({ width: 1 + 3 * (1 - t), color: 0xff7a2b, alpha: 1 - t });
    }
  }
```

```ts
/** Current time, refreshed every `intervalMs`; drives countdowns. */
export function useNow(intervalMs: number): number {
  const [now, setNow] = useState(() => Date.now());
  useEffect(() => {
    const id = setInterval(() => setNow(Date.now()), intervalMs);
    return () => clearInterval(id);
  }, [intervalMs]);
  return now;
}
```

```tsx
import { useEffect, useMemo } from "react";
import styles from "./App.module.css";
import { CanvasView } from "./canvas/CanvasView";
import { GameClient } from "./game/client";
import { gameStore } from "./state/game-store";
import { uiStore } from "./state/ui-store";
import { AuthPanel } from "./ui/AuthPanel";
import { ConfirmBar } from "./ui/ConfirmBar";
import { ExplosionFlash } from "./ui/ExplosionFlash";
import { FreezeBanner } from "./ui/FreezeBanner";
import { Hud } from "./ui/Hud";
import { PaletteBar } from "./ui/PaletteBar";
import { StatusBar } from "./ui/StatusBar";
import { Toasts } from "./ui/Toasts";

const LOGIN_ERRORS: Record<string, string> = {
  denied: "Вход отменён",
  discord: "Не удалось войти через Discord, попробуйте ещё раз",
  state: "Сессия входа устарела, попробуйте ещё раз",
};

export function App() {
  const client = useMemo(() => new GameClient({ game: gameStore, ui: uiStore }), []);

  // The auth redirect reports failures in the query string: show it once and clean the URL.
  useEffect(() => {
    const params = new URLSearchParams(window.location.search);
    const error = params.get("login_error");
    if (error === null) return;
    uiStore.getState().pushToast("error", LOGIN_ERRORS[error] ?? "Не удалось войти");
    params.delete("login_error");
    const search = params.size > 0 ? `?${params.toString()}` : "";
    window.history.replaceState(window.history.state, "", `${window.location.pathname}${search}${window.location.hash}`);
  }, []);

  return (
    <div className={styles.app}>
      <CanvasView client={client} />
      <ExplosionFlash />
      <div className={styles.topLeft}>
        <StatusBar />
        <Hud />
      </div>
      <div className={styles.topRight}>
        <AuthPanel />
      </div>
      <div className={styles.topCenter}>
        <FreezeBanner />
        <Toasts />
      </div>
      <div className={styles.bottom}>
        <ConfirmBar client={client} />
        <PaletteBar />
      </div>
    </div>
  );
}
```
