# План 7: Biome и CI — Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** линтер и форматтер Biome по всему репозиторию и CI на GitHub Actions (спека v1.1, раздел 5). После плана каждый push и PR проверяется: lint → typecheck → тесты с Postgres → сборка клиента → e2e.

**Решения:**

- `@biomejs/biome` строго `2.5.15` в корневых `devDependencies`, один `biome.json` в корне.
- Настройки форматтера подбираются под текущий стиль кода (двойные кавычки, точки с запятой, отступ 2 пробела, длина строки — та, при которой меньше всего правок), чтобы первый прогон не переписал половину файлов.
- Первое форматирование — **отдельный коммит** без других изменений.
- Правила lint: `recommended`. Правила, которые массово срабатывают на текущем коде, выключаются точечно с комментарием о причине в `biome.json`; исправления кода — отдельными коммитами, не вперемешку с фичами.
- Скрипты: `lint` = `biome check .`, `format` = `biome format --write .`, `check:fix` = `biome check --write .`.
- CI — один workflow `.github/workflows/ci.yml`, два job-а:
  - `check`: Bun `1.3.6` (как в `Dockerfile`), `bun install --frozen-lockfile`, `lint`, `typecheck`, `bun test` с сервисом `postgres:17-alpine` (база `rave_test`, `TEST_DATABASE_URL`), `build:web`;
  - `e2e` (после `check`): `bun run e2e` — тот же скрипт, что локально (Docker Compose есть на раннерах GitHub), Chromium из `bunx playwright install --with-deps chromium`.
  - `concurrency` по ветке с отменой устаревших запусков.

**Найдено при подготовке:** `chunk-sync.sim.test.ts` прогоняет 3 000 детерминированных сценариев и на 4 vCPU идёт ~5,8 с при стандартном лимите `bun test` в 5 с. Тест не флакует, он просто медленный: даём ему явный лимит 30 с.

## Задачи

### 1. Медленный тест

- [ ] `apps/web/src/canvas/chunk-sync.sim.test.ts`: третий аргумент `test(..., 30_000)` с комментарием, почему.
- [ ] `bun test` — все тесты зелёные.
- [ ] Коммит `test: give the chunk sync simulation an explicit timeout`.

### 2. Biome

- [ ] `bun add -d --exact @biomejs/biome@2.5.15`.
- [ ] `biome.json`: `files.includes` — исходники, тесты, конфиги; исключены `node_modules`, `dist`, `drizzle/meta`, `bun.lock`, `playwright-report`, `test-results`. VCS-интеграция с `.gitignore`.
- [ ] Подобрать `formatter.lineWidth` по числу изменённых строк (`biome format` без `--write`), выбрать минимальную правку.
- [ ] Скрипты `lint`, `format`, `check:fix` в корневом `package.json`.
- [ ] Коммит `chore: add Biome config` (без форматирования кода).

### 3. Форматирование

- [ ] `bun run format`.
- [ ] `bun run typecheck`, `bun test` — без изменений в результатах.
- [ ] Коммит `style: format with Biome` — только форматирование.

### 4. Lint

- [ ] `bunx biome lint .` — разобрать срабатывания по правилам.
- [ ] Безопасные автоисправления (`--write`, без `--unsafe`) применить отдельным коммитом, если их немного и они очевидны; проверить typecheck и тесты.
- [ ] Массовые или спорные правила выключить в `biome.json` с комментарием.
- [ ] `bun run lint` — ноль ошибок.
- [ ] Коммиты `chore: fix Biome lint findings` / `chore: tune Biome rules`.

### 5. CI

- [ ] `.github/workflows/ci.yml` по решениям выше.
- [ ] README: раздел «Проверки» дополнить `bun run lint` и упоминанием CI.
- [ ] Коммит `ci: lint, typecheck, tests, build and e2e on GitHub Actions`.
- [ ] Push; проверить первый запуск workflow и довести до зелёного.
