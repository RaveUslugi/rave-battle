# План 11: админка на новом ките — Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** админка по спеке ревизии (раздел 6) на компонентах `ui/kit`: боковое меню, дашборд, игроки с карточкой, холст, конфиг-форма с палитрой, журнал. Всё через i18n (спека v1.1, раздел 3: админка переводится целиком). Серверные API готовы с плана 8; сервер не меняется. e2e не добавляются (решение владельца): проверка — модульные тесты и ручной просмотр.

**Решения:**

- **Маршруты** — один экран `/admin`, раздел в `?tab=` (`dashboard` по умолчанию, `players`, `canvas`, `config`, `log`), параметры раздела там же (`player`, `x`, `y`, `area`). Ссылки из игры и журнала ведут сюда.
- **Строки** — секция `admin` в словарях ru/en. Свободный текст админа (причины, комментарии) не переводится.
- **Дашборд** — график по часам своим SVG (столбцы пикселей и линия онлайна), без библиотек.
- **Игроки** — таблица `admin.players.list` (фильтры со счётчиками, сортировка по колонкам, страницы по 50) и поиск `admin.players.search`. Карточка выезжает справа, вкладки «Обзор / Экономика / Модерация / История»; логика бана, правки баланса и отката переносится из нынешней `PlayerCard`. Чат: «Без чата 1 ч / 24 ч / свой срок» с причиной, «Вернуть чат», «Удалить сообщения за сутки».
- **Холст** — тот же `CanvasSession` и `GameClient`, что в игре, но инструмент только «Инспектор» или «Область» (рисовать нельзя). Справа вкладки «Область» и «Клетка» — логика нынешней игровой вкладки модерации. Слои (бомбы, тепловая карта игрока) требуют новых серверных API — отдельной задачей; в этом плане — инспектор, область, зум кнопками.
- **Игровая вкладка «Модерация»** удаляется; у админа в столбце игры — ссылка на `/admin?tab=canvas&x=&y=` с текущей позицией камеры.
- **Конфиг-форма** — метаданные полей в `packages/shared/src/config/form.ts`: путь, единица и множитель отображения (мс → секунды/минуты), шаг, правила предупреждений. Подписи и подсказки — в словарях по пути поля. Тест обходит схему и проверяет, что у каждого числового поля есть метаданные, а у метаданных — поле в схеме.
- **Черновик конфига** — объект той же формы, что `GameConfig`, ошибки схемы раскладываются по путям полей; изменённые поля — золотая рамка и «было N». Награды дня — список строк (что / сколько). Палитра — сетка свотчей и редактор выбранного цвета (тип, параметры эффекта, превью, открытие, цена, названия). Сохранение — с diff в `ConfirmDialog`.
